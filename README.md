# 📈 Emoji Stock Ticker

Generate hilarious stock charts for random objects like pizza slices, lonely socks, and anxiety levels! Perfect for creating printable posters or digital art to sell on Etsy/Gumroad.

## 🎯 Features

- **Random Object Generator**: 25+ funny items with emoji support (Pizza, Coffee, Anxiety, etc.)
- **Chart.js Integration**: Beautiful, professional-looking stock charts
- **PNG Export**: Download charts as high-quality PNG images
- **Realistic Data**: Generates convincing stock-like data with volatility
- **Modern UI**: Responsive design that works on all devices
- **Monetization Guide**: Complete guide on how to turn this into profit

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click "Generate Random Chart" to create funny stock charts
4. Click "Export as PNG" to download your chart
5. Check out `MONETIZATION.md` for tips on selling your charts

## 🎨 How to Use

1. **Generate Charts**: Click the "Generate Random Chart" button to create a new chart for a random funny object
2. **View Stats**: See current value, percentage change, and market cap
3. **Export**: Download your favorite charts as PNG files
4. **Sell**: Follow the monetization guide to turn charts into profit
